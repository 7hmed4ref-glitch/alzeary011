# المنصة التعليمية - Educational Platform

منصة تعليمية متكاملة مصممة للطلاب والمعلمين، توفر نظام إدارة حصص دراسية، امتحانات، بث مباشر، وأكثر.

## ✨ الميزات الرئيسية

### 🎓 للطلاب
- **التسجيل الحقيقي**: تسجيل حساب جديد برقم هاتف مصري وبريد إلكتروني
- **نظام الموافقة**: يجب موافقة الأدمن على التسجيل قبل الدخول
- **الحصص الدراسية**: مشاهدة فيديوهات تعليمية مع تتبع التقدم
- **اختبارات تفاعلية**: كويزات بعد كل حصة مع تصحيح تلقائي
- **الامتحانات**: امتحانات شاملة مع تقييم فوري
- **البث المباشر**: مشاهدة الحصص المباشرة والتفاعل مع المعلمين
- **الأسئلة والاستفسارات**: طرح الأسئلة والحصول على إجابات
- **الشكاوى**: الإبلاغ عن المشاكل التقنية

### 👨‍💼 للأدمن
- **إدارة التسجيل**: قبول أو رفض طلبات تسجيل الطلاب الجدد
- **إدارة الحصص**: إنشاء وتعديل الحصص مع رفع الفيديوهات والملفات
- **إنشاء الاختبارات**: تصميم كويزات لكل حصة مع تحديد الإجابات الصحيحة
- **إدارة الامتحانات**: إنشاء امتحانات شاملة بأسئلة متنوعة
- **البث المباشر**: بدء بث مباشر بالكاميرا والميكروفون
- **إدارة الطلاب**: عرض وإدارة جميع الطلاب المسجلين
- **الإحصائيات**: متابعة أداء الطلاب والنشاط على المنصة

## 🚀 التقنيات المستخدمة

### Frontend
- **React 18** - مكتبة JavaScript لبناء واجهات المستخدم
- **TypeScript** - للكتابة الآمنة والقوية
- **Vite** - أداة بناء سريعة
- **Tailwind CSS** - إطار عمل CSS للتصميم
- **Lucide React** - أيقونات حديثة وجميلة

### الخدمات
- **LocalStorage** - قاعدة بيانات محلية (يمكن استبدالها بـ Firebase/Supabase)
- **WebRTC** - للبث المباشر
- **BroadcastChannel API** - للتواصل بين التبويبات
- **File API** - لرفع الملفات

## 🎯 كيفية الاستخدام

### للأدمن

1. **تسجيل الدخول**
   - استخدم بيانات المدير: `7hmed4ref@gmail.com` / `011156`

2. **إنشاء حصة جديدة**
   - اذهب إلى "الحصص" → "إضافة حصة جديدة"
   - املأ البيانات: العنوان، الوصف، المدة
   - ارفع الفيديو (MP4, WebM, OGG)
   - ارفع ملف PDF (اختياري)
   - أضف أسئلة الكويز (سؤال واحد على الأقل)
   - حدد الإجابة الصحيحة لكل سؤال
   - احفظ الحصة

3. **بدء بث مباشر**
   - اذهب إلى "البث المباشر"
   - أنشئ جلسة بث جديدة
   - اضغط "بدء البث"
   - اسمح بالوصول إلى الكاميرا والميكروفون
   - ابدأ البث!

4. **إنشاء امتحان**
   - اذهب إلى "الامتحانات"
   - اضغط "إنشاء امتحان جديد"
   - املأ البيانات وأضف الأسئلة
   - حدد الإجابات الصحيحة
   - احفظ الامتحان

### للطلاب

1. **تسجيل الدخول**
   - سجل دخول بحسابك أو استخدم الحساب التجريبي

2. **مشاهدة الحصص**
   - اذهب إلى "الحصص الدراسية"
   - اختر حصة مفتوحة
   - شاهد الفيديو بالكامل (95% على الأقل)
   - حل الكويز (60% على الأقل للنجاح)
   - سيتم فتح الحصة التالية تلقائياً

3. **تحميل الملفات**
   - في صفحة الحصة، ستجد ملف PDF أسفل الفيديو
   - اضغط "تحميل الملف" لتنزيله

4. **مشاهدة البث المباشر**
   - اذهب إلى "البث المباشر"
   - ستظهر الجلسات النشطة
   - اضغط "انضم الآن" للمشاهدة

5. **أداء الامتحانات**
   - اذهب إلى "الامتحانات"
   - اختر امتحان متاح
   - أجب على الأسئلة
   - احصل على النتيجة فوراً
